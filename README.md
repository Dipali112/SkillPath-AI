# 🎓 SkillPath AI

SkillPath AI is an intelligent career guidance web platform built to help IT job seekers, students, and early-career developers assess their technical skills, identify skill gaps for specific IT roles, and follow personalized learning roadmaps powered by Google Gemini AI.

---

## 🌟 Key Highlights

- **Role Exploration:** Browse popular IT industry roles with defined prerequisite skills in recommended learning order.
- **AI-Driven Assessment:** Take dynamic technical quizzes generated by Google Gemini AI to evaluate current domain knowledge.
- **Skill Gap Analysis:** Receive automated scoring and a clear breakdown of mastered skills versus missing skills.
- **Personalized Roadmaps:** Access curated learning paths with free tutorials, step completion tracking, and AI career advice.

---

## 🏗️ Architecture Overview

The project is structured as a decoupled two-tier application:

- **Frontend (`skillpath-frontend/`):** Pure HTML5, CSS3, and modern vanilla JavaScript. No framework overhead, fully responsive, and styled with clean component designs.
- **Backend (`skillpath-backend/`):** Node.js and Express.js REST API with MySQL for data persistence, JWT for authentication, and Google Gemini API for generative AI capabilities.
- **Database (`schema.sql`):** Normalized relational schema storing users, profiles, roles, skills, quizzes, and roadmap milestones.

For detailed documentation, setup instructions, and API references, check the dedicated guides in each folder:
- 📖 [Frontend Documentation](./skillpath-frontend/README.md)
- ⚙️ [Backend & API Documentation](./skillpath-backend/README.md)

## 🚀 Quick Start Guide

### 1. Database
Import the schema into your local MySQL instance:
```bash
mysql -u root -p < schema.sql ```



### 2. Backend Server
cd skillpath-backend
npm install
# Configure your .env file (see skillpath-backend/.env.example)
npm start

Runs on http://localhost:5000 (or http://localhost:5001).

### 3. Frontend Client
Open skillpath-frontend/index.html in your browser (or use the VS Code Live Server extension).
